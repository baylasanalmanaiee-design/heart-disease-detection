# Heart Disease Detection

A team-based academic machine learning project developed as part of a university course at Qassim University.

The project explores the use of machine learning techniques to analyze health-related data and predict the presence of heart disease based on selected patient attributes.

## Project Overview

The project follows a machine learning workflow that includes:

- Dataset exploration and understanding
- Data preprocessing and preparation
- Exploratory Data Analysis (EDA)
- Feature analysis
- Classification model development
- Model training and evaluation
- Comparison of model performance

## Objective

The main objective of the project is to investigate how machine learning classification techniques can be applied to heart disease prediction and evaluate their performance using appropriate evaluation metrics.
